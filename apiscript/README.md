# API scripts
## These scripts together make Fuchsia X integrate with the game.

### BreakingPointUtils
These are some more basic utilities that just save time when handling the different modules.

### MaterialLua
This is the ols main UI library.

### bpAPI
(https://github.com/LateAlways/BreakingPointAPI)

This is a library that interfaces with the original Breaking Point game. This library is the one to modify mainly to port Fuchsia X to other Breaking Point games.

### drawing
This is a prototype library that adds partial support for the Drawing library that some executors don't support.

### newuilib
This script is the second UI library. It is the one responsible for the Fuchsia X banner when running the script and the notifications.

### simplepath
This is the library used in AutoPlay for its pathfinding.

Happy scripting!
